## 部署

纯静态站点，单文件 + Tailwind CDN。

- **Vercel**：New Project → Import → Framework `Other` → Deploy。
- **GitHub Pages**：Settings → Pages → Source `main / root` → Save。
- **Netlify**：Import 后直接 Deploy，无需任何构建命令。
